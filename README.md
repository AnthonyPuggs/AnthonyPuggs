### [`ausecon-mcp-server`](https://github.com/AnthonyPuggs/ausecon-mcp-server)

An MCP server for Australian economic data, including RBA and ABS series.

### [`Housing-Affordability-Dashboard`](https://github.com/AnthonyPuggs/Housing-Affordability-Dashboard) · [Live web app ↗](https://anthonypuggs-housing-affordability-dashboard.share.connect.posit.cloud/)

A stylish and interactive Australian macroeconomic dashboard built in R Shiny, with live ABS data pulls through `readabs`.

- Built with `shiny`, `bslib`, `ggplot2`, `plotly`, and `readabs`
- Includes Australian macro indicators such as GDP, CPI inflation, household consumption, labour market indicators, wages, and real cash rate measures
- Supports interactive time-series graphics with zoom, hover, and pan functionality
- Allows custom ABS series IDs to be added from the sidebar
