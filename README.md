## Featured projects

### [ausecon-mcp-server](https://github.com/AnthonyPuggs/ausecon-mcp-server)

A Model Context Protocol (MCP) server that gives LLM clients such as Claude Desktop direct, structured access to official Australian economic data. Instead of relying on memory, a model can pull the actual series it needs, whether that is the cash rate, CPI, GDP or the yield curve, and reason over the numbers.

- Covers RBA statistical tables, ABS datasets and APRA statistics through a single set of tools
- Concept-based lookup for common analyst requests (inflation, unemployment, credit growth, yields) alongside source-native dataset discovery
- Includes a small, transparent set of derived indicators such as real interest rates, growth transformations and yield-curve slope
- Built in Python

### [Housing-Affordability-Dashboard](https://github.com/AnthonyPuggs/Housing-Affordability-Dashboard) · [Live app ↗](https://anthonypuggs-housing-affordability-dashboard.share.connect.posit.cloud/)

An interactive R Shiny dashboard for tracking the Australian macroeconomy and cost-of-living pressures, with live data pulled from the ABS through `readabs`.

- Tracks GDP, CPI inflation, household consumption, labour market indicators, wages and real cash rate measures
- Interactive time-series charts with zoom, hover and pan
- Any ABS series ID can be added from the sidebar, so the dashboard doubles as a general-purpose ABS explorer
- Built with `shiny`, `bslib`, `ggplot2`, `plotly` and `readabs`
